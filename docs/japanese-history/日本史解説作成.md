# 日本史解説作成 — 出題の趣旨と、高校生に伝わる解説の書き方

作成日: 2026-09-15。日本史（共テ対策）に収録する問題（過去問・自作）に `explanation`（正解理由）と `choiceNotes`（選択肢別解説）を書くときの手引き。出題分析は [common-test-analysis-2025-2026.md](common-test-analysis-2025-2026.md)、選定・作問方針は [question-authoring-guidelines.md](question-authoring-guidelines.md)、データ項目は [content-data-requirements.md](content-data-requirements.md) を参照。

## 0. 要点

1. 大学入試センターは「用語などを含めた個別の事実等に関する知識のみならず、歴史に関わる事象の**意味や意義、特色や相互の関連**」を、「歴史的な見方・考え方」（時期や年代、推移、比較、相互の関連、現在とのつながり）を働かせて考察する力を測ると明言している。解説も同じ観点で書く：**「何年に何があった」で終わらせず、「なぜ・その結果・前後と比べて何が変わったか」を必ず添える**（第1節）。
2. 出題側の自己評価では、正答率が低かった設問は「人名や制度、法令などの**歴史用語を用いずに説明した文**について内容や年代の正誤を判断するもの」で、「用語の暗記だけでは解答に至らない」と分析されている。解説では、**選択肢の抽象表現を具体の用語に還元する手順**（逆引き）を明示する（第2.3節）。
3. 資料は現代語訳・注付きで出るが、「資料の立場性」（誰が・何のために・いつ書いたか）を問う設問が両年度にある。解説では**資料中の根拠語句と、資料の性格の判断理由**を書く（第2.4節）。
4. 高校生に伝わる文章の原則は、文化審議会「公用文作成の考え方」を教材向けに翻案して使う：**一文50〜60字以内・一文一論点・結論を先に・3つ以上は箇条書き・専門用語は「言い換える／説明を付ける／そのまま使う」の3区分**（第4節）。
5. `explanation` は「問いの型→正解と根拠→思考手順→誤答の切り方→覚え方・関連」の順、`choiceNotes` は全選択肢に「判定＋根拠＋誤答なら正しくは何か」。型別テンプレートと記入例は第5節。

## 1. 大学入試センターが公表している「出題の趣旨」

### 1.1 問題作成方針（令和8年度＝2026年度試験、令和9年度＝2027年度試験）

大学入試センターは毎年6月に「大学入学共通テスト問題作成方針」を公表する。令和8年度（2026年1月実施）と令和9年度（2027年1月実施）の「歴史総合，日本史探究」に関する記述は同文で、要点は次のとおり（出典：[令和8年度プレス発表資料（2024-06-07）](https://www.dnc.ac.jp/news/albums/abm.php?d=355&f=abm00004500.pdf)、[令和9年度試験情報ページ](https://www.dnc.ac.jp/kyotsu/shiken_jouhou/r9/) 掲載の「問題作成方針」PDF）。

| 項目 | 方針の記述（要約） | 解説作成への含意 |
| --- | --- | --- |
| 基本的な考え方 | 「深い理解を伴った知識の質を問う問題や、知識・技能を活用し思考力・判断力・表現力等を発揮して解くことが求められる問題を重視」。「社会や日常の中から課題を発見し解決方法を構想する場面、資料やデータ等を基に考察する場面、考察したことを整理して表現しようとする場面などを設定」 | 解説は「知識の確認」だけでなく「資料から何を読み、知識とどう結んだか」を再現する |
| 構成・内容 | 「高等学校学習指導要領解説及び高等学校で使用されている教科書を基礎とし、特定の事項や分野に偏りが生じないように留意」。「教科書等で扱われていない資料等も扱う場合がある」 | 根拠は教科書レベルで示す。初見資料は「教科書のどの知識で読めるか」を示す |
| 出題形式 | 「多肢選択式又は数値や記号等で解答する形式」。「**いわゆる連動型の問題**（連続する複数の問いにおいて、前問の答えとその後の問いの答えを組み合わせて解答させ、正答となる組合せが複数ある形式）を出題する場合がある」 | 2026年度第3問問3で実際に出題。解説は「どちらを選んでも成立する2本の筋道」を両方書く（第5.6節） |
| 地理歴史（歴史） | 「歴史に関わる事象を多面的・多角的に考察、構想する過程を重視」。「用語などを含めた個別の事実等に関する知識のみならず、歴史に関わる事象の意味や意義、特色や相互の関連等について、歴史的な見方・考え方を働かせながら、概念などを活用して多面的・多角的に考察したり、課題の解決を視野に入れて構想したりする力を求める」。「『歴史総合』で学習したことと、それを基に『日本史探究』で学習したことを問う」 | 解説の骨格は「意味・意義／特色／相互の関連」。第1問は世界史の文脈と日本を結ぶ |
| 歴史（作成上の検討事項） | 「教科書等で扱われていない資料であっても、そこから得られる情報と授業で学んだ知識を関連付ける問題」「仮説を立てて資料に基づき根拠を示したり検証したりする問題」「時代や地域を超えて特定のテーマについて考察する問題」 | 設問がこの3類型のどれかを解説冒頭で明示すると、受験生が「何を試されたか」を自覚できる |

**部会が両年度の「まとめ」で示した今後の留意点**（同文）

1. 高等学校教育の範囲と水準に深く配慮しながら、標準的な問題を作成する。
2. 学校現場での授業実践にも良いメッセージとなるような出題上の工夫をする。
3. 文字資料だけでなく、画像・地図・表など多様な資料を提示しながら、歴史事象に関する深い理解に至りうるような問題の作成に工夫を凝らす。
4. 授業や探究活動を通じて身に付けた資質・能力の到達度を明確に測れるような出題に努める。

**部会が引用した外部評価のうち、解説の書き方に直結するもの**

- 「人名や事件名、制度の名称など、歴史用語はなるべく使用せずに、理解度を測る表現上の工夫」（両年度）。
- 「比較的正答率が低かった問題は、人名や制度、法令などの歴史用語を用いずに説明した文について内容や年代の正誤を判断するものが多かった。資料から必要な情報を読み取ることができても、関連付ける知識が用語の暗記だけでは解答に至ることができなかった。背景や因果関係を意識して学習内容を説明できるまで理解を深める」（2025年度 高校教員評価）。
- 「原文を読解した上で、資料の立場性を踏まえて思考・判断することを求めた姿勢は興味深く、良問」（2026年度 第3問問4）、「内容理解を踏まえて資料の立場性を考察させる良問」（第5問問3）。
- 「チョルノービリ原子力発電所事故とソ連解体との前後関係をレポート中の『1986年』という年代から読み取らせることは、安易な年代暗記の助長が危惧される」（2026年度 歴史総合第1問への指摘）。→ 解説でも「年号だけで切る」説明を避け、前後関係の理由を添える。
- 「個別の事実等に関する知識の出題に関しては、些末なものではなく、概念的な理解に必要な基本的なものを問うように」（2026年度 高校教員評価）。
- 「文章表現や資料の情報量を精査して、受験者が時間的な余裕をもって解答できる出題上の工夫を」（同）。→ 解説も冗長にしない。

### 1.3 サンプル問題・試作問題からの継続点

2021年公表の「歴史総合」サンプル問題は、「東西冷戦とはどのような対立だったのか」などの**問い**を軸に、会話文・写真・法令・演説・統計を組み合わせ、最後の問で「授業で追究した主題」と「さらに追究するための資料」の組合せを選ばせた（出典：[歴史総合サンプル問題（作成の趣旨付き）](https://www.dnc.ac.jp/albums/abm.php?d=743&f=abm00000306.pdf)）。2025年度第1問問8・第6問問5、2026年度第3問問5の「疑問と調べ方・考察」型は、この設計思想の継続である。解説では「なぜその調べ方が疑問に答えられるのか／答えられないのか」を書く。

## 2. 趣旨から導く「解説が説明すべきこと」

### 2.1 歴史的な見方・考え方の5観点を解説の骨格にする

学習指導要領（部会見解が引用）の「時期や年代、推移、比較、相互の関連や現在とのつながり」を、解説の点検項目として使う。

| 観点 | 解説に入れる内容 | 例（2026年度 解答番号12 弓削島荘） |
| --- | --- | --- |
| 時期・年代 | 出来事の年代と、判断に効く前後関係 | 1239年＝承久の乱（1221）後 |
| 推移 | 前の状態→変化→後の状態 | 荘園領主の支配→地頭の設置と横領→年貢が揃わない |
| 比較 | 似た制度・人物・時代との違い | 国司（朝廷が派遣）と地頭（幕府が任命）の違い |
| 相互の関連 | 因果・目的・影響 | 「関東の」＝幕府側だから地頭 |
| 現在とのつながり（必要なとき） | 現代的課題との接続（歴史総合の設問で特に） | — |

### 2.2 「知識のみ／読解のみ／統合」を解説冒頭で宣言する

分析文書（第2.7節・3.7節）の区分に対応させ、`explanation` の1文目で「この問題は、資料の○○と、教科書の○○を結び付けて判断する問題」のように型を宣言する。受験生が「資料だけ読めばよいのか、知識が要るのか」を最初に知ることで、以降の読み方が定まる。

### 2.3 用語を伏せた選択肢の「逆引き」手順を書く

出題側は「歴史用語をなるべく使用せず」に選択肢を書く。解説では次の順で還元する。

1. 選択肢の抽象表現を引用する（例：「恐慌で経営危機となった銀行を救済する緊急勅令案に、天皇の諮問機関が反対して」）。
2. 各語を具体名に置き換える（恐慌→1927年の金融恐慌、天皇の諮問機関→枢密院、政党内閣→憲政会の第1次若槻礼次郎内閣）。
3. 置き換えた結果、文全体が事実と合うかを判定する。
4. 誤答は「どの語の置き換えで矛盾が出るか」を一点に絞って示す（例：「長期にわたり政権を担当」→第1次大隈内閣は約4か月）。

### 2.4 資料の「立場性」を判断した理由を書く

資料が出たら、解説に次の4点を必ず入れる。

| 項目 | 書くこと | 判断の手がかり |
| --- | --- | --- |
| 誰が | 作成主体（幕府・大名・貴族・僧・生徒のノートなど） | 出典表記・注・宛先 |
| いつ | 成立年と、記述対象の年の差 | 出典の年、会話文のヒント |
| 何のために | 法令・命令／記録・日記／伝聞・書状／評価・史論 | 文末表現（「申し候」「と聞いた」「〜すべし」） |
| 限界 | 伝承・噂・後世の評価は事実と切り分ける | 「〜といわれている」「〜のようだ」 |

2026年度第5問問3（『綿考輯録』の書状）は「申し候」「雑説」から伝聞と判断し、第3問問4（『看聞日記』の伝承）は成立時期と作者の活動期の不一致から伝承を否定する。この判断理由そのものが解説の核になる。

### 2.5 誤答の「型」を名指しする

分析文書の傾向T8に対応する誤答分類を解説に書く。受験生は「型」で覚えると次の問題に転用できる。

| 型 | 名称（`distractorRationales.category`） | 一言の説明例 |
| --- | --- | --- |
| 時代錯誤 | `anachronism` | 「CISは1991年以降。1986年には存在しない」 |
| 主体の取り違え | `wrong-agent` | 「知行国主は国司ではない」 |
| 因果逆転 | `reversed-causality` | 「以仁王の子を保護＝平氏との対立であって協調ではない」 |
| 過剰一般化 | `overgeneralization` | 「『いずれも』と言えるか、表を全行確認する」 |
| 程度の誇張 | `exaggeration` | 「『継続的に協調』は初期議会の実態と逆」 |
| 別事件の帰結 | `other-event` | 「八色の姓は壬申の乱後の天武朝の施策」 |
| 用語混同 | `term-confusion` | 「甘葛と砂糖は別物」 |
| 範囲のずれ | `scope-shift` | 「近代史の設問に戦後の概念（第三世界）を混ぜている」 |

## 3. 大学入試の日本史解説はどう書かれているか（観察）

手元の予備校解説（東進：`nihonshi-tankyu.pdf`、`nihonshi-tankyu-2.pdf`、`nihonshi-b-2.pdf`、`nihonshi-b-4.pdf`）と受験参考書の記述を観察し、本アプリの解説に取り入れる点・取り入れない点を整理する。

| 観察された書き方 | 例 | 取り入れ方 |
| --- | --- | --- |
| 「正解は④。」から始め、次に正答の根拠、続けて他の選択肢を番号順に判定 | 東進解説の全設問 | 採用。ただし `choiceNotes` は選択肢の並び順で書く |
| 資料の語句を「」で引用して根拠にする（「『申し候』とされていたため」） | 2026年度第5問問3の解説 | 採用。引用は20字以内、必ず資料のどこかを示す |
| 年代を括弧で添える（永享の乱（1438〜1439）） | 各所 | 採用。判断に効く年代だけに絞る |
| 「〜は誤り」で終わる短い判定 | 旧課程の解説に多い | 不採用。「正しくは何か」まで書く（既存科目の方針と同じ） |
| 「〜と判断できたはずである」「多くの受験生は…できたと思われる」という講評 | 東進解説 | 不採用。学習者向けの解説では評価の言葉を省き、手順だけ書く |
| 「知識がなくても読解のみで導けるか」の検討 | 2025年度第1問問7の解説 | 部分採用。読解だけで切れる選択肢と、知識が要る選択肢を分けて示す |
| 「流れ」と「枠組み」（今どの時代・分野か、前の時代から何が変わったか）を先に押さえる学習法 | 旺文社「共通テスト『歴史総合，日本史探究』の内容と勉強法」 | 採用。`explanation` の末尾「関連・覚え方」で時代の枠組みに位置づける |
| 「資料から情報を読み取ること、読み取った情報と歴史事象を紐づけて考えること」 | Z会 2026年度分析 | 採用。第2.2節の型宣言に対応 |

参考にした公開資料：[旺文社 共通テスト「歴史総合，日本史探究」の内容と勉強法（PDF）](https://service.obunsha.co.jp/tokuten/rekishisougou_otasuke/dl/nihonshi_benkyoho.pdf)、[Z会 歴史総合，日本史探究 2026年度共通テストの分析＆対策の指針](https://www.zkai.co.jp/kyotsu-test/bunseki/nihonshi/)、[河合塾 2025年度 歴史総合，日本史探究 分析](https://www.kawai-juku.ac.jp/nyushi/kyotsutest/25/analysis/5210/)。

## 4. 高校生に理解しやすい書き方（文章の原則）

文化審議会建議「[公用文作成の考え方](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93651301_01.pdf)」（2022年1月）は「広く一般に向けた文書では、義務教育で学ぶ範囲の知識で理解できるように書く」ことを掲げ、文の書き方の具体的指針を示している。これを教材の解説向けに翻案する。

| 原則（建議の記述） | 解説での運用 |
| --- | --- |
| 「一文を短くする」「50〜60字ほどになってきたら読みにくくなっていないか確認」 | 一文は原則50字以内、最長60字。長くなったら句点で切るか、修飾節を別文にする |
| 「一文の論点は、一つにする」 | 「Aであり、またBであるが、Cではない」を3文に分ける |
| 「三つ以上の情報を並べるときには、箇条書を利用する」 | `explanation` は改行で段落を分け、手順は「まず／次に／最後に」か番号で示す |
| 「基本的な語順（いつ・どこで・誰が・何を・どうした）」 | 歴史の説明文は「いつ・誰が・何を・なぜ」の順を守る |
| 「結論は早めに示し、続けて理由や詳細を説明する」 | 1文目に正答と結論。理由はその後 |
| 専門用語は「言い換える／説明を付けて使う／普及を図るべき用語は工夫してそのまま用いる」 | 教科書太字の用語はそのまま使い、初出で括弧の説明を付ける（例：「令外官（令に規定のない官職）」）。太字でない語は言い換える |
| 「『等』『など』の類は、慎重に使う」「代表的・典型的なものを挙げる」 | 「〜など」の前には必ず代表例を1つ以上書く |
| 「図表を効果的に用いる」 | 年代の前後関係や制度の対比は、2〜3行の簡易表か「A→B→C」の矢印で示す |
| 「文語の名残に当たる言い方は、分かりやすい口語体に言い換える」 | 史料の原文は解説で現代語に直して引く |

**解説の文体**：既存教材（公共政経・化学）と同じ「だ・である」調。敬語・呼びかけ（「〜しましょう」）は使わない。数字は算用数字、年は西暦、必要な場合だけ元号を括弧で添える（例：1615年（元和元年））。

**高校生がつまずく箇所への配慮**

- 同音・類似の用語（永享の乱／応永の乱、旧里帰農令／人返しの法）は、解説で必ず対にして違いを書く。
- 人物は「役職＋名前」で初出させる（「3代執権北条泰時」）。
- 「〜以前／以後」「〜前半／後半」は具体年を1つ添える。
- 計算を含む問題（2026年度 解答番号10）は式を1行で示す（1000−400＝600、600÷2＝300）。
- 図・地図・グラフの解説は「どこを見るか（軸・凡例・位置）」を先に書き、読み取った値を次に書く。

## 5. 執筆テンプレートと記入例

### 5.1 `explanation` の構成（全型共通）

```
【型】この問題は、（資料の○○）と（教科書の○○）を結び付けて判断する問題。   ← 1文
【正解】○番（組合せ型は「あ・X」のように内訳も）。                       ← 1文
【根拠】資料の「…」から○○が分かる。教科書知識では、○○（いつ・誰が・なぜ）。 ← 2〜4文
【手順】まず…。次に…。最後に…。                                        ← 2〜4文（読解→知識→照合）
【誤答の切り方】△番は「…」が（型名）。□番は…。                            ← 各1文（choiceNotes と重複しすぎない）
【関連・覚え方】この出来事は「（時代の枠組み）」の中で、前の…から後の…へ変わる節目。 ← 1〜2文
```

長さの目安：300〜600字。連動型・複数資料型は800字まで可。

### 5.2 `choiceNotes` の構成（全選択肢分）

```
正解の選択肢: 「正解。（根拠）。（補足：なぜこれが最も適当か）」
誤答の選択肢: 「（判定）。（誤りの箇所を引用）は（型名）。正しくは（事実）。」
```

各60〜150字。「誤り。」だけで終わらせない。組合せ型（あ・X型）では、選択肢ごとに「あ／い」「X／Y」の両方の判定を書く。

### 5.3 型別の追加事項

| 型 | 追加で書くこと |
| --- | --- |
| 正文・誤文4択 | 「最も適当」の場合、他の選択肢が「部分的に正しいが○○の点で不適当」であることを明示 |
| 2文正誤・メモ正誤 | 各文を独立に判定した結果を先に表で示す（あ：正、い：誤）。「両方正」「両方誤」が正答のときは「消去法が効かない」ことを一言 |
| 4文2択（あ・う型） | 4文すべての判定を書き、正しい2文の組合せが一意になる理由を示す |
| 空欄組合せ | 空欄の前後の語句（「にもかかわらず」「新例」など）を引用し、それが判断の決め手になる理由を書く |
| 2群組合せ | 群ごとに独立して判定。片方だけで選択肢が2つに絞れることを示す |
| 整序 | 3つの出来事に年代を付けたうえで、「取り違えやすい2つの前後」を1組取り上げて理由を書く |
| グラフ・表 | 読む位置（何年の棒、どの行）と値を書き、閾値（「3分の2以上」「400万人超」）の計算を示す |
| 地図・概念図 | 凡例と位置関係を文章化し、画像がなくても追えるようにする |
| 資料の性格判定 | 文末表現・宛先・出典から「法令／記録／伝聞／評価」のどれかを判断した理由 |
| 探究方法・考察 | 各調べ方が「疑問に答えられるか」「時期が合うか」の2点で判定 |
| 連動 | 第5.6節 |

### 5.4 記入例1：資料＋知識の2群組合せ（2026年度 第2問問4、解答番号12、正解③）

`explanation`

> この問題は、鎌倉時代の荘園から出された年貢の報告（現代語訳）と、承久の乱後の地頭についての教科書知識を結び付けて判断する問題。
> 正解は③（い・X）。
> 空欄エには「地頭」が入る。資料には「近年、関東の［エ］が置かれるようになってから」年貢が揃わなくなった、とある。「関東」は鎌倉幕府を指す言い方なので、幕府が任命して荘園に置いた役職、つまり地頭である。国司は朝廷が国ごとに派遣する地方官で、「関東の」とは呼ばない。
> 承久の乱（1221年）に幕府が勝つと、上皇方の所領に多くの地頭が新たに置かれ、荘園領主の取り分を横領する動きが目立つようになった。資料の1239年はその直後にあたる。
> 読み取れる内容は、Xが適当。資料は荘園の年貢物の報告であり、「公物分」は荘園領主（この荘園では東寺）に納める分である。Yの「朝廷に上納」は、荘園の年貢の宛先を取り違えている。
> 手順は、まず「関東の」から幕府側の役職と特定し、次に資料の性格（荘園領主への報告）から年貢の宛先を確定する、の2段階。
> この設問は「荘園公領制の中で、地頭が荘園領主の権利を侵していく」という鎌倉時代の流れの一場面である。地頭請・下地中分（13世紀後半）へつながる前段階として位置づけて覚える。

`choiceNotes`（①〜④の順）

> ① あ（国司）・X。国司は朝廷が派遣する官で、資料の「関東の」と合わない。Xは適当だが、エが誤りなので不適当。
> ② あ（国司）・Y。エも読み取りも誤り。Yの「朝廷に上納」は年貢の宛先の取り違え。荘園の年貢は荘園領主に納める。
> ③ 正解。い（地頭）・X。「関東の」＝幕府が置いた役職＝地頭。「公物分」は荘園領主（東寺）に上納された分で、資料が「荘園の年貢物の報告」であることと一致する。
> ④ い（地頭）・Y。エは正しいが、Yは誤り。「預所得分」は荘園を管理する預所の取り分であり、朝廷に上納するものではない。

### 5.5 記入例2：2文正誤（2026年度 第6問問1、解答番号30、正解③）

`explanation`

> この問題は、会話文の「55年体制末期に成立した、国連平和維持活動への自衛隊派遣を可能にする法律」を特定したうえで、その背景と直後の政治を知識で判定する問題。
> 正解は③（あ：誤、い：正）。
> 法律はPKO協力法（1992年、宮沢喜一内閣）である。
> いは正しい。1991年の湾岸戦争で日本は多国籍軍に総額130億ドルを支援したが、人的貢献がないとして国際的に評価されず、自衛隊を海外に派遣できる仕組みが求められた。これがPKO協力法の直接の背景である。
> あは誤り。自由民主党・日本社会党・新党さきがけの連立（村山富市内閣）は1994年、つまり1993年の細川護熙内閣成立で55年体制が終わった後のことである。日本社会党が自衛隊容認へ方針転換したのも村山内閣期で、PKO協力法の成立（1992年）より後。「55年体制末期」という会話文の条件と時期が合わない。
> 「両方正」でも「両方誤」でもない組合せなので、片方ずつ独立に判定する。
> 覚え方：湾岸戦争（1991）→PKO協力法（1992、宮沢）→55年体制崩壊（1993、細川）→自社さ連立（1994、村山）の順。

### 5.6 記入例3：連動型（2026年度 第3問問3、解答番号16・17、正解は①→⑤ または ②→⑥）

連動型では、`explanation` に**2本の筋道を両方**書き、どちらを選んでも採点上は同じ配点であることを明記する。`choiceNotes`（解答番号17の6択）は、各選択肢が「どの出来事の帰結か」を書く。

`explanation`（解答番号17側）

> この問題は、(1)で自分が選んだ古代の政変について、その政変が「政治の転換の契機」になった理由を選ぶ連動型の問題。(1)で①（あ）を選んだ場合は⑤、②（い）を選んだ場合は⑥が正解で、どちらの組合せでも得点は同じ。片方だけ合っていても得点にならない。
> あは、7世紀半ばに大臣として権勢を振るった一族の父子（蘇我蝦夷・入鹿）が滅ぼされた乙巳の変（645年）。この政変を機に大化改新が始まり、地方行政組織として評が置かれるなど中央集権化が進んだ。したがって⑤。
> いは、太上天皇（平城）と天皇（嵯峨）が平城京への遷都をめぐって対立し、太上天皇の側近（藤原仲成・薬子）が殺害・自害した平城太上天皇の変（810年）。この変の際に嵯峨天皇は蔵人所を設け、天皇の命令が蔵人を通して太政官に伝わる仕組みができた。したがって⑥。
> 残りの4つは別の政変の帰結である。①八色の姓は壬申の乱後の天武天皇、②近江遷都と庚午年籍は白村江の戦い後の天智天皇、③僧侶（道鏡）の太政大臣禅師・法王就任は恵美押勝の乱後、④摂政・関白の常置は安和の変（969年）後。
> 覚え方：「政変→直後の制度改革」を対で押さえる。乙巳の変→評・改新の詔、白村江→近江遷都・庚午年籍、壬申の乱→八色の姓、恵美押勝の乱→道鏡、薬子の変→蔵人所、安和の変→摂関常置。

## 6. 解説の品質チェックリスト

収録前に、`explanation` と `choiceNotes` について次を確認する（作問方針の第6節と重複する項目は省略）。

- [ ] 1文目で問題の型（資料／知識／統合）を宣言している。
- [ ] 正答と、組合せ型の内訳を2文目までに書いている。
- [ ] 資料の根拠を「」で引用し、資料のどこかを示している。
- [ ] 知識の根拠を「いつ・誰が・何を・なぜ」で書いている。
- [ ] 抽象表現の選択肢は、具体名への置き換えを示している。
- [ ] 資料の立場性（誰が・いつ・何のために・限界）に触れている（資料問題のみ）。
- [ ] 全選択肢の `choiceNotes` に判定・根拠・（誤答なら）正しい事実がある。
- [ ] 誤答の型を1つ以上名指ししている。
- [ ] 一文50〜60字以内、一文一論点、3項目以上は箇条書きか矢印。
- [ ] 教科書太字でない用語に説明を付けている。「など」の前に代表例がある。
- [ ] 年号だけで切る説明になっていない（前後関係の理由がある）。
- [ ] 「〜できたはずである」などの講評語がない。
- [ ] 連動型は両方の筋道と採点規則を書いている。
- [ ] 年代・人名・制度名を教科書または一次資料で再確認した（`factCheckedAt`）。
