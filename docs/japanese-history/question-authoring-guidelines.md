# 日本史（共テ対策）問題の選定・作問方針

作成日: 2026-09-15。根拠となる出題分析は [common-test-analysis-2025-2026.md](common-test-analysis-2025-2026.md)（以下「分析」。傾向ID T1〜T12・要件ID R1〜R11 はそこで定義）。データ項目は [content-data-requirements.md](content-data-requirements.md)。

## 0. 要点

- 本アプリの日本史教材は2本立てである。(A) 共通テスト「歴史総合，日本史探究」・「日本史B」・センター試験「日本史B」の過去問を**選定して収録**し、解説を加筆する（公共政経・化学と同じ運用。権利面の扱いは `NEXT_WORK.md`「過去問利用の権利確認（2026-09-03 判断済み）」に従う）。(B) 収録の空白を埋める**自作の補強問題**を作る。本文書は (A) の選定基準（第1.6節）と、(A)(B) 共通の型・難易度・解説・品質基準を定める。解説の書き方の詳細は [日本史解説作成.md](日本史解説作成.md)。
- 1問ごとに「型（第2節）」「難易度6軸（第3節）」「知識層（分析第5節）」「時代・分野」をタグ付けし、模試ブループリント（第1.4節）に沿って比率を管理する。
- 解説は「正答＋思考手順＋必要知識＋資料中の根拠＋全誤答の理由＋復習タグ＋出典」を必須とする（第4節）。
- 公開前にファクトチェック・一意性・著作権・アクセシビリティのチェックリスト（第6節・第7節）を通す。不合格条件に1つでも該当したら収録しない。

## 1. 科目・コース設計

### 1.1 名称と識別子

| 用途 | 値 | 備考 |
| --- | --- | --- |
| 正式名称（出典表記・解説文・模試名） | 共通テスト「歴史総合，日本史探究」 | 現行の正式科目名。旧課程は「日本史B」 |
| 短縮表示（科目えらびタイル・見出し） | 日本史（共テ対策） | 既存 `public/subjects.js` の `name` と同じ |
| 内部識別子 | `japanese-history`（ID接頭辞 `jhist-`） | 既存の `subjects.js` と `validate-content.mjs` に登録済み |
| 出典区分 | `common-new`（新課程）／`common-legacy`（日本史B）／`center`／`original` | 既存の `JHIST_SOURCE_TYPES` |

ユーザーが便宜的に「日本史総合」と呼ぶことがあっても、画面・文書には正式名称か短縮表示のどちらかを使い、「日本史総合」という科目名は表示しない。

### 1.2 対象学習者と前提知識

- 対象：共通テストで「歴史総合，日本史探究」を受験する高校生・受験生。中学歴史の通史と、歴史総合（18世紀以降の世界と日本）の既習を前提とする。
- 前提知識の水準：教科書レベル（分析第5節の層1〜3）。層6（世界史的背景）は歴史総合の教科書範囲に限定し、世界史探究固有の細部（分析で「日本史探究の教科書では確認できない」と評された穀物法のような項目）は、出題する場合でも資料内にヒントを置く（T2、2025年度 解答番号3 の教訓）。

### 1.3 「歴史総合」と「日本史探究」の比率・接続

| 領域 | 配点上の比率（本試験） | アプリでの扱い |
| --- | --- | --- |
| 歴史総合（第1問） | 25/100 | 世界史を含む近現代。地図・グラフ・表・パネルを主資料に、日本の出来事と国際的文脈を必ず接続する（T2） |
| 日本史探究（第2〜6問） | 75/100 | テーマ史15＋原始古代15＋中世15＋近世15＋近現代15（T4） |

接続の作法：歴史総合の設問でも日本の関与（条約・植民地・移民・災害支援など）を1問は含める（2026年度 解答番号2・6・8 の型）。日本史探究の近現代でも国際関係（ワシントン会議・PKO）を含める（2026年度 30・33）。

型の目安は2026年度の実績を基準にしたもので、2025型では単独4択（正文・誤文）と整序を増やす（分析4.2）。両型を交互に出して形式の偏りを防ぐ（T5）。

### 1.5 ローテーション規則（偏り防止）

同じ模試内・連続する模試の間で、次の重複を禁止または制限する。

| 対象 | 規則 |
| --- | --- |
| 人物 | 同一人物を正答の鍵にする小問は模試内で1回まで。連続3模試で同一人物を鍵にしない |
| 時代 | 第3〜6問の時代は固定だが、各大問内で「同じ世紀」に3問以上偏らせない |
| 資料形式 | 模試内で同じ主資料タイプは最大3回。地図・グラフ・絵画・史料文・ノートを必ず各1回以上 |
| 型 | 単独4択が全体の50%を超えない。組合せ型が75%を超えない。整序は1〜3問 |
| 正答位置 | 4択の正答番号は模試内で各番号5〜10回に収める（順序依存の問題は除外） |
| 「両方正」「両方誤」 | 2文正誤・メモ正誤のうち少なくとも1問は「両方正」または「両方誤」を正答にする（T12） |
| テーマ | 第1問・第2問のテーマは過去に使ったものと6模試以上あける（テーマ一覧は `theme` タグで管理） |

### 1.6 過去問の選定方針（収録基準）

化学の実装計画「2.2 出典／2.3 収録しないもの／2.4 依頼のされ方と作り分け」に倣い、日本史向けに定める。

| 区分 | 基準 |
| --- | --- |
| 収録単位 | 原則として**解答番号ごとに1レコード**。大問のリード文・資料を必要とする小問は、同じ `groupId` で大問単位にまとめ、共通資料は `groupFigures`／`stem` に載せる（日本史は資料依存の小問が多いため、化学の「1問で完結するものだけ」より緩くする） |
| 連動型 | 2026年度第3問問3のような連動型は、選択側と従属側の2レコードを同じ `gradingUnit` で収録する（[content-data-requirements.md](content-data-requirements.md) 第4節）。採点未対応の間は従属側を代表正答で単独採点し、`explanation` に両方の筋道を書く |
| 優先して収録するもの | 「知識と資料の統合」型（分析 T7 の6〜7割）、「資料の性格」を問う型、用語を伏せた選択肢（T10）、連動型、探究方法の妥当性（T9） |
| 比率を管理して収録するもの | 読解だけで解ける設問（例：2026年度 解答番号4・10。高校教員評価も「読解力があれば解答できる」と指摘）は「資料読解演習」として収録できるが、全体の1割程度に抑える |
| 収録しないもの | 図版・地図が判読できない画質のもの、原本の資料が長すぎてスマートフォンで読めないもの（要約して `stem` に載せられない場合）、正解が公式正解表で確認できないもの |
| 解説の作り方 | 予備校解説（東進など）が手元にある場合はそれを正としつつ、そのまま貼らず `choiceNotes` に分解し、誤答は「どこが・どう違うか・正しくは何か」を書く。手元にない場合は教科書レベルの根拠で自作し、自信が持てない設問は収録しない（化学 2.4 と同じ） |
| 出典・確認 | `sourceType`（`common-new`／`common-legacy`／`center`）、`year`（「2026年度」）、`sourceQuestion`（「第3問 問3（解答番号16・17）」）、`sourceUrl`、`verifiedAt` を必須。正解は公式正解表で照合する |
| 図版 | 冊子から切り出して `public/images/japanese-history/` に置き、`imageAlt` を必ず付ける（化学の運用と同じ） |
| 時代・分野の空白 | 過去問だけでは埋まらない `field` は、自作問題（B）で補う。どの `field` が空白かは収録後に集計する（`NEXT_WORK.md` P1「過去問台帳」の手順） |

## 2. 小問テンプレート

各テンプレートは「目的／構成／適する知識層／選択肢数／難易度調整／典型誤答／作問上の注意」で定義する。知識層は分析第5節、誤答分類はT8による。

### 2.1 史料文＋基礎知識

- 目的：初見の史料（現代語訳または原文＋注）から情報を取り、教科書知識で意味づけする（2026年度 解答番号12・20・25）。
- 構成：史料（現代語訳150〜300字、原文なら注3〜5個）＋設問文＋4択。史料に書かれている事実1〜2点と、知識で判定する事実2〜3点を選択肢に混ぜる。
- 知識層：1・2・4・5。
- 選択肢数：4（正文／誤文／2群組合せ）。
- 難易度調整：史料の長さ、注の数、抽象表現（「関東の○○」）の有無、知識で判定する選択肢の数。
- 典型誤答：史料に書かれていない因果の挿入、主体の取り違え（国司／地頭、朝廷／幕府）、成立時期と矛盾する出来事。
- 注意：史料の出典・成立年・作成主体を必ず明示する。原文を出す場合は現代語訳を解説に載せる。史料は自作要約か、パブリックドメインの古文書を自前で現代語訳する（第7節）。

### 2.2 複数史料の比較

- 目的：2〜3点の史料の共通点・相違点・成立時期の違いから、評価や事実を判定する（2026年度 20・27、2025年度 20）。
- 構成：史料A・B（各100〜200字）＋設問。「両史料ともに〜と評価している」「Aは法令、Bは伝聞」のように**資料の性格**を問う選択肢を1つ以上入れる（T9）。
- 知識層：4が中心、1・2で補強。
- 選択肢数：4（正文4択、2群組合せ）。6択（史料×主張の組合せ）も可（2024年度 第6問問1の型）。
- 難易度調整：史料の成立時期の近さ、文末表現（「申し候」「〜と聞いている」）の解釈が必要かどうか。
- 典型誤答：「13世紀に成立した資料である」のように片方だけ正しい複合文、伝聞を法令と誤読させる文。
- 注意：史料の性格判定の根拠（文末表現・宛先・注）が史料中に必ずあること。

### 2.3 地図・空間情報

- 目的：地図上の位置・範囲・矢印から事実を読み、政治体制・地域区分の知識と接続する（2026年度 1・5、2025年度 5）。
- 構成：自作の地図（簡略な白地図に凡例2〜4種）＋説明文＋設問。
- 知識層：2・5・6。
- 選択肢数：4（空欄組合せ、4文2択、メモ正誤）。
- 難易度調整：凡例の重なり（「二つが重なる地域」）の有無、時期表示（月・年）の数、政治体制など地図外の知識の要否。
- 典型誤答：「特定の地域にのみ見られた」型の過小一般化、時期の前後逆転。
- 注意：地図は自作（オープンデータの境界データや手描き模式図）とし、色だけで区別しない（第7.4節）。代替テキストで凡例と位置関係を文章化する。

### 2.4 年表・年代整序

- 目的：出来事の前後関係を把握する（2026年度 32、2025年度 7・26・31）。
- 構成：Ⅰ〜Ⅲの文（各30〜60字、固有名詞を伏せて説明文で書く：T10）＋6択。または年表の空欄・挿入位置（2024年度 第1問問1の型）。
- 知識層：1・2。
- 選択肢数：6（整序）または4（年表挿入）。
- 難易度調整：3つの出来事の間隔（10年以内なら難）、固有名詞の伏せ方、同一人物・同一テーマで揃えるか。
- 典型誤答：なし（整序は組合せで決まる）。誤り方の分析は解説で「どの2つの前後を取り違えやすいか」を書く。
- 注意：`noShuffle: true` 必須。整序は模試1回に1〜3問（分析4.2）。

### 2.5 統計表・グラフ

- 目的：数値の読み取り（比率・増減・最大最小）と、時期に対応する出来事の知識を統合する（2026年度 4・7、2025年度 6・28）。
- 構成：自作グラフ（棒・折れ線・円）または表（3〜6行）＋「読み取れる事柄」あ〜う＋「当時の状況」X・Y、または誤文4択。
- 知識層：2・5。
- 選択肢数：4または6（3×2組合せ）。
- 難易度調整：読み取り項目の数、単位換算の要否、「〜以上」「最も」の閾値判断、知識側の年代の近さ。
- 典型誤答：比率と実数の混同、「増えた」と「割合が増えた」の混同、期間のずれ。
- 注意：数値は自作・公的統計（出典表記）に限る。グラフは数値表を併記し、色に頼らず凡例を文字で付ける。数値読解だけで解ける小問は大問内に1問まで（T7、読解のみ6%）。

### 2.6 絵画・写真・文化財

- 目的：絵画資料・復元図・文化財写真から時代・用途・担い手を読み、文化史の知識と接続する（2026年度 9・11・14・31、2025年度 18・20）。
- 構成：画像（パブリックドメインまたは許諾済み）＋注記（人物・道具のラベル）＋設問。
- 知識層：1・2・4・5。
- 選択肢数：4。
- 難易度調整：画像から読める情報の量（ラベルの有無）、文化期の判定の細かさ（桃山／元禄／宝暦天明）。
- 典型誤答：別の文化期の作品・技法、画像に描かれていない主体の挿入。
- 注意：画像の権利確認は第7節。画像が読み込めない環境でも解けるよう、判定に必要な情報は注記テキストにも置く。

### 2.7 会話・ノート・レポートの空欄補充

- 目的：探究の文脈（生徒のノート・レポート）の論旨を追い、空欄に入る語句・文を確定する（2026年度 2・5・10・14・22・33、2025年度 3・21・22）。
- 構成：ノート（箇条書き3〜6行、空欄ア・イ）＋語句・文の組合せ4択。
- 知識層：1・3・5。
- 選択肢数：4。
- 難易度調整：空欄が語句か文か、前後の文脈だけで絞れるか、算術（分配・比率）を含むか（T11）。
- 典型誤答：時代錯誤の語句（CIS／ソ連、第三世界）、因果逆転の文（協調／対立）。
- 注意：空欄の前後に判断根拠を必ず置く（「にもかかわらず」「新例を開く」など）。ノート体裁は生徒の言葉で書き、教科書の文章をそのまま貼らない。

### 2.8 正誤文の組合せ

- 目的：2〜4個の命題を独立に判定する（2026年度 1・3・13・18・21・28・30・31）。
- 構成：（a）2文正誤4択、（b）メモ・下線部の「○のみ正しい」4択、（c）4文から正しい2つの組合せ4択。
- 知識層：全層。
- 選択肢数：4。
- 難易度調整：各文の複合度（前半正・後半誤の複文は難）、判定に資料参照が必要な文の数。
- 典型誤答：「いずれも」「すべて」型の過剰一般化、前半正・後半誤。
- 注意：`noShuffle: true` 必須。「両方正」「両方誤」を正答にする問題を意図的に作る（T12）。4文2択では正しい2文の組合せが一意になるよう、誤りの文2つは明確な誤りにする。

### 2.9 探究方法・追加調査の妥当性

- 目的：疑問に対して適切な「調べ方」「考察」を選ぶ（2026年度 19、2025年度 8・33）。
- 構成：疑問あ・い＋調べ方／考察W〜Z＋2群組合せ4択。
- 知識層：2・3・4。
- 選択肢数：4。
- 難易度調整：不適切な調べ方の理由が「時期のずれ」（易）か「調べても疑問に答えられない」（難）か。
- 典型誤答：時代が合わない資料、疑問とは別の問いに答える調査。
- 注意：正答の調べ方が実際に存在する資料（投票率の統計、屛風絵など）に基づくこと。

### 2.10 歴史総合と日本史探究を横断する設問

- 目的：世界史的出来事と日本の出来事を同一の時系列・因果で結ぶ（2026年度 2・7、2025年度 1・2・8）。
- 構成：表・グラフ・パネルに各国の事例を並べ、日本の事例（下関条約、排日移民法、関東大震災）を含める。
- 知識層：1・2・6。
- 選択肢数：4または6。
- 難易度調整：世界史側の知識を資料内に置くか、受験生の知識に頼るか。
- 典型誤答：戦後の概念（第三世界）を戦前に置く時代錯誤、日本と他国の出来事の前後逆転。
- 注意：世界史側の知識は歴史総合の教科書範囲に限る（第1.2節）。

### 2.11 複数解答番号・連動解答を使う設問

- 目的：受験生が自分で「問い」を選び、その問いに対応する答えを選ぶ（2026年度 16・17）。
- 構成：(1) あ／いから1つ選ぶ（解答番号A、①②）→ (2) (1)で選んだ出来事の帰結・理由を6択から選ぶ（解答番号B）。正答は「Aが①ならBは⑤、②なら⑥」のように条件付き。(2)の6択のうち正答2つ以外は、別の出来事の帰結（知識の総点検になる）。
- 知識層：1・2・3。
- 選択肢数：(1) 2、(2) 6。
- 難易度調整：(2)の誤答選択肢がどれだけ近い時代・似た帰結か。
- 典型誤答：別事件の帰結、同じ事件の前提（原因）を帰結と取り違え。
- 注意：採点は1採点単位（3点）で、AとBの組合せが正答表のいずれかに一致したときのみ得点。データ表現は [content-data-requirements.md](content-data-requirements.md) 第4節。同型を模試1回に1問まで。

## 4. 解説の品質基準

各問題の `explanation` と `choiceNotes` には最低限、次を含める。「正解は○番。○○だから。」だけの解説は**不合格**。

| 項目 | 内容 | 保存先 |
| --- | --- | --- |
| 正答 | 番号と、組合せ型なら各要素（あ・X 等）の内訳 | `explanation` 冒頭 |
| 思考手順 | 「資料から○を読む→知識で年代化→照合」の順で2〜4段階 | `explanation`（`reasoningSteps` にも配列で） |
| 必要な基礎知識 | 判定に使った教科書知識を「いつ・誰が・何のため」で1〜3点 | `explanation`（`requiredKnowledge`） |
| 資料中の根拠 | 資料のどの語句・数値・位置が根拠か（引用は20字以内） | `explanation` |
| 各誤答が誤りである理由 | 全選択肢分。誤答分類（時代錯誤／主体取り違え／因果逆転／過剰一般化／程度の誇張／別事件の帰結）を明示 | `choiceNotes`（`distractorRationales`） |
| 関連知識と復習タグ | 同テーマの隣接事項と `knowledgeTags` | `explanation` 末尾、タグ |
| 出典と権利 | 資料の出典（自作なら「自作」）、画像のライセンス | `sourceCitations`、`license` |

文体：既存教材（公共政経・化学）と同じく「だ・である」調、1解説300〜600字、`choiceNotes` は各60〜150字。用語の初出には簡単な説明を添える。

## 5. 作問工程

1. **設計票を書く**（問題本文を書く前）：大問テーマ、時代、型、知識層、6軸難易度、主資料の種類、正答にする命題、誤答の分類、参照する傾向ID。

5. **自己チェック**（第6.1節）。
6. **別視点レビュー**（第6.2節、作成者以外か、作成から1日以上あけた本人）。
7. **ファクトチェック記録**：`factCheckedAt`、確認に使った資料名を `reviewNotes` に。
8. **収録**：`reviewStatus: "approved"` にしてから `content/japanese-history/questions/*.json` に追加し、`npm run validate:content` を通す（実データ投入は本文書の範囲外）。

## 6. ファクトチェック・品質保証

### 6.1 自己チェックリスト

- [ ] 年代・人物・制度・地名を、教科書レベルの資料2点以上（または一次資料・公的資料1点）で確認した。

- [ ] 誤答選択肢の誤り方が第2節の分類のどれかに当てはまり、解説に書かれている。
- [ ] 順序依存の選択肢に `noShuffle: true` を付けた。
- [ ] 旧字・異体字・ルビ・現代語訳の扱いが第7.5節に従う。
- [ ] OCR・転記ミス：数値・年号・人名をもう一度原資料と突き合わせた。

### 6.2 別視点レビュー項目（作成者以外）

- 設問文を読まずに資料と選択肢だけを見て、正答が推測できてしまわないか（選択肢の長さ・具体性の偏り）。
- 正答の選択肢だけが「教科書の言い回し」になっていないか。
- 受験生の誤読を誘う表現が「意図した紛らわしさ」の範囲か（引っかけのための引っかけになっていないか）。
- 既存の共通テスト・センター試験問題との類似（テーマ＋資料＋選択肢の構成が同一なら不合格）。
- 解説の思考手順が、設問の資料と知識だけで追えるか。

### 6.3 公開前チェックリストと不合格条件

**不合格条件（1つでも該当したら収録しない）**

1. 正答が一意に定まらない、または公式見解と異なる正答を採用している。
2. 自作問題（`sourceType: "original"`）なのに、過去問の本文・選択肢・図版を転載、または語句を置き換えただけの複製になっている。
3. 画像・史料の権利が不明。
4. 図表に代替テキストがない。
5. `choiceNotes` が全選択肢分そろっていない、または「正解だから」で終わる。
6. 連動採点の正答組合せが `acceptedAnswerCombinations` に列挙されていない。
7. `verifiedAt`・`factCheckedAt`・`reviewStatus: approved` のいずれかが欠けている。

**公開前チェック**：`npm run validate:content` 成功、上記7条件の不該当、模試ブループリントの比率（第1.4節・第1.5節）を満たすこと。

## 7. 著作権・出典・アクセシビリティ

### 7.1 過去問の扱いと、自作問題の素材の優先順位

- **過去問の収録（A）**：公共政経・化学と同じく、大学入試センター公表の問題を出典（`sourceLabel`・`sourceQuestion`・`sourceUrl`・`year`）付きで収録する。権利面は `NEXT_WORK.md`「過去問利用の権利確認（2026-09-03 判断済み・作業しない）」の判断（個人利用、URLを渡す相手を限定、センターへの利用申請は行わない）に従い、この文書で再検討しない。方針を変えるときは同記録から追跡する。原本・正解資料の入手元は `sources/INDEX.md` に記録する。
- **自作問題（B）**：過去問の本文・選択肢・図版を、そのまま、あるいは表現だけ変えて「自作」と称して入れない（`sourceType: "original"` の問題は出典が過去問でないことを明示する、という既存の決まりと同じ）。素材の優先順位：①自作（要約・模式図・グラフ）、②パブリックドメイン（著作権保護期間満了の古文書・絵画・写真、国立国会図書館デジタルコレクション等の「保護期間満了」表示のもの）、③利用許諾済み、④公的オープンデータ（e-Stat、国土数値情報などライセンス明記のもの）。
- 過去問と同じ史料（例：御成敗式目、武家諸法度）を自作問題で使うこと自体は可。ただし史料の切り取り範囲・注・設問構成を独自に設計する。

### 7.2 引用と出典表記

- 史料の引用は必要最小限（設問に必要な範囲）にし、出典（書名・所蔵・成立年）を資料の直下に表記する。
- 現代語訳・要約は自作とし、「（現代語訳）」「（要約）」を明示する。
- 画像は `sourceCitations` にタイトル・所蔵・URL・ライセンス・取得日を記録し、改変（トリミング・注記追加）した場合は「改変あり」と書く。

### 7.3 画像ライセンス管理項目

`license`（CC0／PD／CC BY 4.0／許諾／自作）、`rightsStatus`（confirmed／pending／unknown）、`rightsNote`（確認方法）。`unknown` の画像は収録しない（不合格条件3）。

### 7.4 アクセシビリティ

- すべての画像・地図・グラフに代替テキスト（`imageAlt`／`alt`）を付ける。基準：凡例の内容、位置関係、判定に必要な数値・語句を文章で再現し、画像なしでも解けること。
- 色だけに依存しない：凡例は模様・線種・文字ラベルを併用。グラフには数値表を併記。
- スマートフォンで読める文字サイズ：画像内の文字は最小でも表示幅の1/40程度、注記はテキスト側にも置く。拡大表示（ピンチズーム）を妨げない。
- 表は `stem` のテキストでも再現し、画像だけにしない。

### 7.5 史料の旧字・異体字・ルビ・現代語訳

- 原文を示す場合は常用漢字に改め、読みにくい語にはルビまたは注を付ける（本試験の「注1）〜」の様式に倣う）。
- 固有名詞（人名・地名）の異体字は教科書表記に統一し、異なる表記は解説で補足する。
- 現代語訳を主とし、原文は「資料の性格（文末表現・伝聞）」を問う場合に限って併記する（2.2節）。

### 9.2 重複防止

- `theme`・`eras`・`knowledgeTags`・`skillTags`・`questionType`（型）を全問に付け、収録前に「同じ `theme`＋同じ `questionType`＋同じ正答の鍵となる `knowledgeTags`」の組が既存問題と一致しないことを機械的に検査する（検査スクリプトは将来の実装課題）。
- 同一の史料・画像を鍵にする問題は300問中3問まで。
- 同一人物を正答の鍵にする問題は300問中5問まで、かつ型を変える。
- 過去問由来の問題（`sourceType` が `common-new`／`common-legacy`／`center`）を収録する場合は、`sourceQuestion`（年度・大問・問・解答番号）で一意性を保証し、自作問題（`original`）とは別ファイルに置く。
