# 日本史（共テ対策）設計文書

科目「日本史（共テ対策）」（内部ID `japanese-history`、ID接頭辞 `jhist-`）に、共通テスト「歴史総合，日本史探究」の過去問を**選定して収録**し、解説を加筆し、空白を自作問題で補うための文書群。2026-09-15 作成。この文書群は「問題の選定方針」と「解説を加筆するときの方針」として使う。

## 目的と範囲

- 2025年度・2026年度の共通テスト「歴史総合，日本史探究」（本試験）を中心に、2023・2024年度「日本史B」を比較基準として、形式・出題傾向・要求知識・資料読解の思考手順を分析する。
- 分析を、過去問の選定基準、自作問題の作問ルール、難易度設計、解説基準、品質保証、著作権・アクセシビリティ方針に変換する。
- 大学入試センターが公表する「問題作成方針」「問題評価・分析委員会報告書」から出題の趣旨を整理し、高校生に伝わる解説の書き方をまとめる。
- 問題データが将来必要とする項目を、既存スキーマ（`scripts/validate-content.mjs`・`src/types.ts`・`public/subjects.js`）との差分として設計する。
- 範囲外：アプリ本体のコード・設定・依存関係の変更。実際の問題データの作成手順と記録はリポジトリ直下の [共テ日本史収録.md](../../共テ日本史収録.md)（2026-09-16 に2026年度本試験34問を収録し、`draft` を外した）。

## 更新方針

- 新年度の共通テストが公表されたら、分析文書に設問単位の表と集計を追加し、傾向ID・要件IDを更新する。作問方針の比率（第1.4節・第9節）はその集計に合わせて見直す。
- 作問方針・データ要件を変えたら、根拠となる傾向ID・要件IDを必ず書く。データ項目を追加したら `schemaVersion` を上げ、データ要件文書の差分表を更新する。
- 分析文書の各主張には `(ファイル名, PDF p.XX)` の根拠を付ける。根拠のない推測は「推定」「要確認」と明記する。
