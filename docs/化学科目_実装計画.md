## 1. この科目を追加した理由

もともと1科目（公共・政治経済）専用に見えていたが、アプリの土台は
`public/subjects.js`（科目マニフェスト）で複数科目を扱えるように作られている。
科目が2つ以上になると、起動時に **科目えらび画面（ホーム）** が自動で開き、
タイルをタップした科目のデータだけを後から読み込む。したがって化学を足しても、
公共・政治経済の起動時間・保存領域・学習記録には影響しない。

## 2. コンセプト

### 2.1 何を集めるか

大学入試の化学のうち、**マーク式（客観式）で、選択肢の正誤判断そのものが問われる問題**を集める。
具体的には次の3つの問い方である。

| 問い方（`askType`） | 画面表示 | 例 |
| --- | --- | --- |
| `correct` | 正しいものを選べ | 「正しいものを一つ選べ」「適当なものを選べ」 |
| `incorrect` | 誤っているものを選べ | 「誤りを含むものを選べ」「適当でないものを選べ」 |
| `true-false` | 正誤の判定・組合せ | 「a〜dの正誤の組合せとして正しいものを選べ」 |

計算主体の問題・構造決定の一連の問題ではなく、**知識問題の対策**が目的である。
計算を含む選択肢でも、選択肢ごとの正誤を知識で切れるものは収録してよい。

### 2.2 出典

| `sourceType` | 対象 |
| --- | --- |
| `common-test` | 大学入学共通テスト「化学」（本試験・追再試験） |
| `center` | 大学入試センター試験「化学」「化学I」「化学II」 |
| `national` | 国公立大学の一般入試（マーク式の設問） |
| `private` | 私立大学の一般入試（マーク式の設問） |
| `original` | 収録の空白を埋めるための自作問題（出典が過去問でないことを明示する） |

私大・国公立の問題は、大問全体ではなく **1問で完結するマーク設問だけ**を切り出す。
前の設問の答えを使う設問、リード文を読まないと成立しない設問は収録しない
（どうしても収録したいときは、必要な条件を `stem` に転記して1問で完結させる）。

### 2.3 収録しないもの

- 記述・論述、構造式を書かせる問題（このアプリの化学では扱わない）
- 数値をマークする計算問題（選択肢の正誤判断がない問題）
- 図・グラフそのものを読み取らないと解けない問題（図を載せても解けないもの）
- リード文・他の小問と読み合わせないと解けない問題

### 2.4 依頼のされ方と作り分け

利用者（依頼者）からの渡され方は2通りある。どちらでも、受験生の学習効果を最大にする
解説を作ることを最優先にする。

1. **問題＋解答解説が渡される場合** — 渡された解説を正とする。ただしそのまま貼らず、
   選択肢ごとの `choiceNotes` に分解し、誤りの選択肢は「どこが」「どう違うか」「正しくは何か」を書く。
2. **問題だけが渡される場合** — 化学の専門家・予備校講師として解答と解説を作成する。
   正解の根拠は教科書レベルの原理に戻して示し、迷いやすい選択肢には判断の決め手を書く。
   自信が持てない設問は収録せず、その旨を依頼者に伝える（誤答を載せない方が学習効果は高い）。

どちらの場合も守ること:

- `explanation` は「何を問う問題か → 正解の根拠 → 覚え方・引っかけの型」の順で書く。
- `choiceNotes` は **全選択肢ぶん**書く。正解の選択肢にも「なぜ正しいか」を書く。
- 単なる「誤り」で終わらせず、**正しい記述に直したらどうなるか**まで書く。
- 数値・法則名・人名は、教科書または一次資料で確認してから書く。

## 3. 分類（`domain` と `field`）

大分野 `domain` は4つ。小分野 `field` は下表から選ぶ（この順で画面に並ぶ）。

| `domain` | `field`（小分野） |
| --- | --- |
| 理論化学 | 物質の構成と化学結合 / 物質量と化学反応式 / 酸と塩基 / 酸化還元 / 電池と電気分解 / 物質の三態 / 気体の性質 / 溶液の性質 / 熱化学 / 反応速度 / 化学平衡 |
| 無機化学 | 周期表と元素の性質 / 非金属元素 / 典型金属元素 / 遷移元素 / 金属イオンの分離と検出 / 無機工業化学 |
| 有機化学 | 有機化合物の構造と異性体 / 脂肪族炭化水素 / アルコールとカルボニル化合物 / カルボン酸とエステル / 芳香族化合物 / 有機化合物の分離と検出 |
| 高分子化合物 | 糖類 / アミノ酸とタンパク質 / 核酸 / 合成高分子 / 天然高分子と繊維 |

`topic`（論点）は問題固有の内容を具体的に書く（例: `両性元素の水酸化物の溶解`）。
表にない `field` を使いたくなったら、まずこの表を改訂し、`public/subjects.js` の
`fieldOrder` も同時に直す（表と `fieldOrder` は必ず一致させる）。

## 4. ファイルの置き場所

| 置き場所 | 中身 |
| --- | --- |
| `content/chemistry/questions/*.json` | 化学の教材（**手で編集するのはここだけ**） |
| `content/chemistry/excluded/*.json` | 方針に合わず外した問題（ビルド対象外） |
| `public/subjects/chemistry/questions.js` | 自動生成物（`npm run build:questions`）。直接編集しない |
| `public/images/chemistry/` | 図・グラフ（webp。`scripts/convert-images.mjs` で変換） |
| `public/subjects.js` | 科目マニフェスト。件数・分類の並び・出典表示名 |

ファイル名は `01-riron.json`（理論）・`02-muki.json`（無機）・`03-yuuki.json`（有機）・
`04-koubunshi.json`（高分子）を基本にし、**ファイル名順 → 配列順**に連結される。

## 5. 教材データの仕様

問題1件は次の形にする（`*` は必須。検査は `npm run validate:content`）。

```json
{
  "id": "chem-2024-kyotsu-honshi-1-3",
  "type": "choice",
  "category": "大学入試過去問",
  "sourceType": "common-test",
  "sourceLabel": "令和6年度 大学入学共通テスト 本試験「化学」",
  "sourceQuestion": "第1問 問3",
  "sourceUrl": "https://www.dnc.ac.jp/...",
  "year": "2024年度",
  "domain": "理論化学",
  "field": "物質の構成と化学結合",
  "topic": "結晶の種類と性質",
  "listTitle": "結晶の種類と性質に関する正誤問題",
  "askType": "incorrect",
  "points": 3,
  "noShuffle": true,
  "question": "…として誤っているものを、次の①〜⑤のうちから一つ選べ。",
  "choices": ["…", "…", "…", "…", "…"],
  "answer": 2,
  "explanation": "…",
  "choiceNotes": ["…", "…", "…", "…", "…"],
  "verifiedAt": "2026-09-09"
}
```

| 項目 | 規約 |
| --- | --- |
| `id`* | **`chem-` で始める**。科目をまたいで一意（学習記録がIDで紐づくため） |
| `domain`* | 理論化学 / 無機化学 / 有機化学 / 高分子化合物 |
| `field`* | 3章の表から選ぶ |
| `topic`* | 問題固有の論点 |
| `listTitle`* | 一覧に出す短い問題名。「〜に関する◯◯問題」の形・40字以内 |
| `askType`* | `correct` / `incorrect` / `true-false` |
| `sourceType`* | 2.2の5種類 |
| `sourceLabel`* | 「2024年度 ◯◯大学 前期日程「化学」」のように、年度・大学・科目まで書く |
| `year` | `2024年度` のように西暦の年度で書く（共通テストも西暦にそろえる）。過去問では必須、自作問題（`original`）は書かない |
| `answer`* | **0始まり**。原本の①は `0` |
| `choiceNotes`* | `choices` と同数 |
| `verifiedAt`* | 正解と内容を最後に確認した日（`YYYY-MM-DD`） |
| `noShuffle` | 「①と②」「すべて正しい」など、並べ替えると壊れる選択肢に付ける |
| `image` / `imageAlt` | 図を載せるときは代替テキスト必須 |
| `sourceNote` | 出題当時と現在で扱いが違うときに書く |

**選択肢のシャッフルに注意する。** 化学の正誤問題は「a・bのみ正しい」型の選択肢が多い。
そうした問題には必ず `noShuffle: true` を付ける。付け忘れを防ぐため、次のどちらかに当てはまる問題で
`noShuffle` が無いと `validate:content` が落ちるようにしてある。

- `askType` が `true-false`（正誤の組合せ）
- 選択肢に `①`〜`⑨`・「すべて」・「いずれも」・「上記」・「正しいものはない」が含まれる

## 6. アプリ側の土台（実装済み）

- `public/subjects.js` に `chemistry` を追加。科目が2つになったので、起動時に科目えらび画面が出る。
- `scripts/build-questions.mjs` は科目マニフェストの `contentDir` を見て、
  科目ごとに `public/subjects/<id>/questions.js` を生成する。
- `scripts/validate-content.mjs` に化学用の検査（`contentProfile: "chemistry"`）を追加。
  分野・出典・問い方・出典名・確認日・選択肢別解説・一覧名を検査する。
- 出典の表示名・大分野の並び・小分野の並びは科目ごとに `public/subjects.js` で持つ。
- 演習範囲に **「問い方別」**（正しいもの／誤っているもの／正誤の組合せ）を追加した。
  `askType` を持つ問題がある科目でだけ表示される（公共・政治経済では出ない）。
- 年度の並び替えは `2024年度` のような西暦表記にも対応した。
- 称号（レベルの呼び名）も `public/subjects.js` の `ranks` で科目ごとに変えられる。
- 演習の途中でアプリが読み込み直されたときは、科目えらびを挟まずその演習へ戻る。

学習記録・復習予定・同期・バックアップの仕組みは科目共通で、IDの接頭辞（`civics-` / `chem-`）で
分かれる。既存の公共・政治経済の記録には影響しない。

## 7. 教材を1回追加するときの手順

1. 渡された問題を2.1・2.3の基準で選別する（収録しないものはその理由を依頼者に返す）。
2. `content/chemistry/questions/*.json` に追記する（`listTitle`・`askType` を忘れない）。
3. 解説を作る（2.4の作り分け）。
4. `public/subjects.js` の `expectQuestions` と `expectDomainCounts` を実際の数に更新する。
5. `npm run build:questions` で公開用データを生成する。
6. `npm run check`（生成 → 教材検証 → 型検査 → ビルド → テスト）を通す。
7. スマートフォン幅で問題文・選択肢・解説の見え方を確認する。
8. コミットし、`npm run deploy` で公開する。
9. この文書の「9. 作業記録」に1行足す。
